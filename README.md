# 写真コラージュ（額縁）アプリ

登録済みの額縁に写真を1枚入れて、Instagram投稿向けの比率で書き出せるWebアプリです。

## 機能

- 初期額縁は **ゴールドギャラリー** と **ローズソフト** の2種
- 額縁の追加・削除（ローカルストレージ）
- フレームパーツ作成（上下帯固定＋マスコット別配置）
- マスコットはドラッグで配置
- 写真を1枚配置（拡大・位置調整）
- Instagram向けアスペクト比で書き出し
  - フィード推奨: **4:5**（1080×1350）
  - 正方形: **1:1**（1080×1080）
  - ストーリーズ: **9:16**（1080×1920）

## 開発

```bash
npm install
npm run dev
```
