# 写真コラージュ（額縁）アプリ

登録済みの額縁に写真を1枚入れて、Instagram投稿向けの比率で書き出せるWebアプリです。

## 機能

- 額縁 10種から選択（先頭は ECCジュニア大学前教室の上下イラスト枠）
- 写真を1枚配置（拡大・位置調整）
- Instagram向けアスペクト比で書き出し
  - フィード推奨: **4:5**（1080×1350）
  - 正方形: **1:1**（1080×1080）
  - ストーリーズ: **9:16**（1080×1920）

## イラスト枠アセット

`public/frames/` に上下イラストを登録しています（中央の写真は含めません）。

## 開発

```bash
npm install
npm run dev
```
